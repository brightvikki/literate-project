# Literate Project

A starter native Android app built with Kotlin and Jetpack Compose.

## Open the project

1. Open this repository in Android Studio (Ladybug or newer recommended).
2. Allow Gradle to sync and install the Android SDK platform requested by the project (API 35).
3. Run the `app` configuration on an emulator or Android device.

The project uses JDK 17, Android Gradle Plugin 8.7.3, Kotlin 2.0.21, and Jetpack Compose.

## Customize

The sample screen is in `app/src/main/java/com/brightvikki/literateproject/MainActivity.kt`. Update the app name in `app/src/main/res/values/strings.xml` and the application ID in `app/build.gradle.kts` as needed.
